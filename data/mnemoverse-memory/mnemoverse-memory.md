## Overview

Mnemoverse Memory is an MIT-licensed MCP server for agent memory, backed by a hosted engine that re-ranks recall from reported outcomes rather than similarity alone, with one key shared across Claude Code, Cursor, VS Code, and ChatGPT.

## Features

- Tell it a recalled memory helped or misled, and it re-ranks what comes back next
- One key shared across Claude Code, Cursor, VS Code, and ChatGPT
- Remote MCP endpoint `https://mcp.mnemoverse.com/mcp` with OAuth sign-in
- npm package `@mnemoverse/mcp-memory-server`, listed in the official MCP Registry as `io.github.mnemoverse/mcp-memory-server`

## Pricing

Free, Pro, Team, and Enterprise tiers. The MCP server is MIT-licensed; the memory engine is hosted.
