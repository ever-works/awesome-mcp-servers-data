## Overview

Budna MCP gives MCP clients read-only access to public data from Budna, a
Swedish second-hand marketplace. It needs no account or API key and cannot
change marketplace data.

## Features

- Search listings, categories, filters, and filter options
- Inspect listings, attributes, related listings, and seller listings
- Public seller profiles, bid summaries, and rating summaries
- Interactive listing cards in clients that support MCP Apps

## Installation

```bash
npx --yes @budna-marketplace/mcp
```

Also available via Cargo (`budna-mcp`), Homebrew, and prebuilt binaries.
