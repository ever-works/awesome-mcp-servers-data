## Overview

Fincept MCP is a hosted Model Context Protocol server for Fincept Terminal. It
gives coding agents and MCP clients 440 platform tools and 15 quant engines.
Users sign in once through the browser with OAuth 2.1.

## Features

- Market quotes, OHLCV candles, option chains, futures curves, fundamentals and
  symbol search
- Global economic series and SEC filings
- News, sentiment and alternative data
- Portfolio analytics, screeners and strategy backtests
- Fincept Paper trading account (no real money)
- Quant engines for statistics, ML and statistical forecasting, GARCH
  volatility, panel econometrics, 201 technical indicators, change points,
  regimes, copulas, portfolio optimisation and fixed-income/derivatives pricing

## Connection

- Endpoint: `https://enterprise.fincept.in/mcp` (remote, Streamable HTTP)
- Auth: OAuth 2.1 browser sign-in, no API key
- Works with any MCP client that supports remote servers
- Docs: https://docs.fincept.in
- Official MCP Registry id: `in.fincept/mcp`
