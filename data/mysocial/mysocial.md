# Mysocial

Mysocial brings a creator's connected social media history, performance signals, and creator memory into MCP-compatible AI clients.

## Connection

- Hosted endpoint: https://app.mysocial.io/mcp
- Transport: Streamable HTTP
- Authentication: OAuth 2.1 with dynamic client registration; a Mysocial account is required.
- Setup documentation: https://mysocial.io/mcp/
- Public integration metadata and agent skills: https://github.com/mysocialio/mysocial-intelligence

The public metadata and skills repository is MIT licensed. The hosted service backend is proprietary. Mysocial offers Free and paid plans; Content Memory and deeper intelligence depend on the selected plan.
