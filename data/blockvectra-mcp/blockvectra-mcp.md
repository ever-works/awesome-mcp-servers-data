## Overview

BlockVectra is a remote MCP server for Robinhood Chain and other EVM networks. It provides documentation search, chain discovery, JSON-RPC and indexed blockchain data.

## Connection

Use `https://docs.blockvectra.com/mcp` with a Streamable HTTP client. Documentation, discovery, pricing and status need no API key. RPC access follows per-chain public method policies; indexed Data API and account tools require a BlockVectra API key supplied through client headers.

See the [setup guide](https://github.com/blockvectra/mcp#install-in-one-step) for client configuration and the [Robinhood Chain guide](https://docs.blockvectra.com/en/guides/robinhood-chain/?ref=everworks-20261102) for mainnet and testnet tasks.
